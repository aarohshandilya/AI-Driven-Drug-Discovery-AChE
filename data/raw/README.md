# Raw data

Raw Kaggle files are intentionally not committed. Run `python backend/data_processing/fetch_kaggle_dataset.py` to download the [Human acetylcholinesterase Dataset from ChEMBL](https://www.kaggle.com/datasets/gauravan/human-acetylcholinesterase-dataset-from-chembl). Kaggle reports the dataset license as Unknown; consult [`../../docs/KAGGLE_DATA.md`](../../docs/KAGGLE_DATA.md) before reuse or redistribution. The Kaggle CSV identifies target CHEMBL220 and Homo sapiens and preserves ChEMBL assay metadata.
